Absolument ! Une fonction safe_realloc est une excellente idée pour gérer les réallocations de mémoire de manière sécurisée et centralisée. Elle permet de réallouer de la mémoire tout en vérifiant les erreurs et en évitant les fuites de mémoire.

Implémentation de safe_realloc
c
Copy

void *safe_realloc(void *ptr, size_t size)
{
    void *new_ptr;

    new_ptr = realloc(ptr, size);
    if (!new_ptr && size > 0) // Vérifie si la réallocation a échoué
    {
        print_error("realloc", "memory allocation failed");
        free(ptr); // Libère l'ancien pointeur pour éviter une fuite de mémoire
        exit(EXIT_FAILURE);
    }
    return (new_ptr);
}

Explications :

    realloc(ptr, size) : Réalloue la mémoire pointée par ptr à la nouvelle taille size.

    Vérification des erreurs : Si realloc échoue, la fonction affiche une erreur et quitte le programme.

    Libération de l'ancien pointeur : Si realloc échoue, free(ptr) est appelé pour éviter une fuite de mémoire.

    Retour du nouveau pointeur : Si la réallocation réussit, la fonction retourne le nouveau pointeur.

Voici comment tu peux implémenter ta propre version de realloc, que nous appellerons ft_realloc, ainsi qu'une version sécurisée safe_ft_realloc.
Implémentation de ft_realloc
Fonctionnement :

    Si ptr est NULL, ft_realloc se comporte comme malloc.

    Si size est 0, ft_realloc se comporte comme free.

    Sinon, ft_realloc alloue un nouveau bloc de mémoire, copie les données de l'ancien bloc vers le nouveau, et libère l'ancien bloc.

Code :
c
Copy

#include <stdlib.h>
#include <string.h> // Pour memcpy

void *ft_realloc(void *ptr, size_t old_size, size_t new_size)
{
    void *new_ptr;

    // Si new_size est 0, libère le bloc de mémoire
    if (new_size == 0)
    {
        free(ptr);
        return (NULL);
    }

    // Si ptr est NULL, alloue un nouveau bloc
    if (!ptr)
        return (malloc(new_size));

    // Alloue un nouveau bloc de mémoire
    new_ptr = malloc(new_size);
    if (!new_ptr)
        return (NULL);

    // Copie les données de l'ancien bloc vers le nouveau
    size_t copy_size = (old_size < new_size) ? old_size : new_size;
    memcpy(new_ptr, ptr, copy_size);

    // Libère l'ancien bloc
    free(ptr);

    return (new_ptr);
}
